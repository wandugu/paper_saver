# Public sources for the multi-image datasets

| Dataset | Paper | Author repository and release instructions |
| --- | --- | --- |
| MRE-MI | [MRE-MI: A Multi-image Dataset for Multimodal Relation Extraction in Social Media Posts](https://aclanthology.org/2025.findings-naacl.351/) | [MRE-MI README at the recorded revision](https://github.com/JinFish/MRE-MI/blob/7ffd3c128855da54f32eb09ffa4c61c5997afb54/README.md) |
| MNER-MI-Plus | [MNER-MI: A Multi-image Dataset for Multimodal Named Entity Recognition in Social Media](https://aclanthology.org/2024.lrec-main.1001/) | [MNER-MI README at the recorded revision](https://github.com/JinFish/MNER-MI/blob/9d625f05fabef2202f36cb85cd203c6f1cd704b5/README.md) |

The author's MNER-MI repository also distributes MNER-MI-Plus. Its README
names the Plus annotations `MNER-UNI_{train,val,test}.txt`. Published
counts refer to relation pairs or tweets as defined by the respective papers.
The logged P24 experiments used MNRE.
